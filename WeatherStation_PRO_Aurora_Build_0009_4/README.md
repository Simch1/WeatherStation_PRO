# WeatherStation PRO — Aurora Build 0009.4

**Status: Stable — tested by the project author on the Freenove ESP32 3.2-inch touchscreen.**

## What's new

- Replaced the temperature graph on the Charts page with an atmospheric pressure bar chart.
- Added pressure values and `hPa` units on the left-hand axis.
- Improved the spacing and readability of the pressure scale.
- Simplified the hour labels below the bars by removing minutes and leading zeros (for example, `06:00` → `6`).
- Preserved the Italian and English interface and the other existing features.

- [Build 0009.2](../WeatherStation_PRO_Aurora_Build_0009_2/): Previous firmware revision.

Download the repository, open this build's firmware directory, and keep all `.ino`, `.cpp`, and `.h` source files together. See the [main README](../README.md) for installation instructions, requirements, video tutorials, and PDF guides.
